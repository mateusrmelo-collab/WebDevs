04 / SEM PONTO DE INTERROGAÇÃO

Antes do
primeiro commit.

Algumas respostas para você
chegar com tudo.

Preciso saber programar para começar?

Não. A proposta é começar pelos fundamentos de HTML e CSS e avançar para lógica, interfaces e banco de dados. Você não precisa dominar uma linguagem antes de dar o primeiro passo.

Quais tecnologias fazem parte do curso?

HTML, CSS, JavaScript, React, PHP e SQL com MySQL formam a base da jornada. A trilha também inclui Git, GitHub e publicação de projetos. A stack pessoal de Mateus é mais ampla e está na seção “Quem ensina”.

Quando acontece o lançamento?

Em 15 de setembro de 2026. A contagem regressiva desta página considera a meia-noite, no horário de Brasília (UTC−3). Você pode salvar a data no seu calendário para não esquecer.

Qual é o valor e como será o acesso?

Os valores, o formato das aulas e as condições de acesso ainda não foram divulgados nesta página. Esses detalhes serão apresentados no lançamento. Salvar a data não é uma inscrição nem uma compra.

O que preciso para acompanhar?

Um computador, conexão com a internet e vontade de praticar. Navegador, editor de código e ferramentas gratuitas compõem o ambiente de desenvolvimento. Os requisitos específicos serão informados com a grade detalhada.
